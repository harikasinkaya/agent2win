🤖 AGENT SPECIFICATION

agent2win Protocol & API Specification

Standard HTTP REST and WebSocket interface for AI Agents (ChatGPT, Gemini, Grok, Claude, Custom GPTs, LangChain) to monitor, interact with, and automate Windows PC / Server environments.

⚡ Port: 7770 🔒 Auth: Bearer Token 🌐 Tunnel: Cloudflare / ngrok 🖥️ PyPI: agent2win v1.0.0 🔌 WebSocket: /ws
🖥️ Recommended Background Execution Workflow

Agents can isolate their active work on a secondary virtual desktop so the human operator can watch videos or work uninterrupted on Desktop 1.

STEP 1
POST /api/desktops/setup
Create agent workspace
STEP 2
POST /api/desktops/switch_agent
Shift context to agent workspace
STEP 3
GET /api/screen & /api/mouse/click
Inspect & run tasks
STEP 4
POST /api/desktops/switch_user
Return view back to user

⚡ 1. System & Information

GET /api/info
Returns OS version, CPU/RAM utilization, hostname, active mode, and uptime.
GET /api/settings
Fetch current server configuration parameters.

📸 2. Screen & Window Management

GET /api/screen
Captures full display and returns a Base64-encoded JPEG image with screen dimensions.
GET /api/windows
Lists all top-level open application windows, titles, bounding boxes, and hwnd handles.
POST /api/windows/screenshot
Capture only the specified window handle.
{"hwnd": 198274}
POST /api/windows/focus
Bring targeted window to foreground.
{"hwnd": 198274}
POST /api/windows/geometry
Set position and size of a window.
{"hwnd": 198274, "x": 0, "y": 0, "width": 1280, "height": 800}

🖱️ 3. Input Emulation (Mouse & Keyboard)

POST /api/mouse/click
Emulates mouse clicks at specific (x, y) screen pixel coordinates.
{"x": 500, "y": 300, "button": "left", "clicks": 1}
POST /api/mouse/scroll
Scroll vertically (positive = up, negative = down).
{"clicks": -5}
POST /api/keyboard/type
Types text with support for UTF-8 and special language characters via clipboard automation.
{"text": "agent2win automation text", "unicode": true}
POST /api/keyboard/hotkey
Press keyboard key combinations simultaneously.
{"keys": ["ctrl", "shift", "esc"]}

💻 4. Command Execution & Shell

POST /api/command
Executes a shell command on Windows and returns stdout, stderr, and exit code.
{"cmd": "ipconfig /all", "timeout": 15}

📁 5. Filesystem & Storage

GET /api/files/list?path=C:\Users
Lists directory entries, sizes, permissions, and timestamps.
GET /api/files/read?path=C:\config.json
Reads text or raw file data from the specified path.
POST /api/files/write
Writes content to target path.
{"path": "C:\\Users\\Public\\script.py", "content": "print('hello')"}

🚀 6. Process & App Control

GET /api/processes
Lists all active OS processes with PID, CPU %, Memory, and executable path.
POST /api/processes/launch
Launches an application binary or script.
{"path": "notepad.exe", "args": ["C:\\log.txt"]}
POST /api/processes/kill
Terminates a process by PID.
{"pid": 4912}

🔧 7. System Subsystems

POST /api/clipboard
Get or set Windows clipboard text.
{"text": "Data copied from agent"}
POST /api/audio/volume
Get or set master audio output volume (0-100).
{"level": 40}
POST /api/registry/read
Read keys and values from Windows Registry.
{"hive": "HKCU", "path": "Software\\Microsoft\\Windows", "name": "Version"}
POST /api/power/lock
Lock workstation screen immediately. (Also supports /api/power/sleep, /api/power/restart).

🔌 8. Real-time WebSocket Protocol

WSS /ws
Real-time bi-directional control stream. Send JSON message payload matching any REST action.
{"action": "command", "cmd": "dir C:\\"}
