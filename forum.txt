🚀 **agent2win: Control Windows with Web AIs (ChatGPT, Gemini, Grok, Claude)!**

Hey everyone! 👋

I built **`agent2win`**, an open-source bridge allowing web-based AIs (ChatGPT, Gemini, Grok, Claude) or cloud frameworks (LangChain, AutoGen) to remotely control your Windows PC/Server via REST & WebSocket!

📦 **Install:** `pip install agent2win`

---

### ✨ Key Features
- 🖥️ **Virtual Desktop Isolation:** Agent works on Desktop 2 while you game/work on Desktop 1.
- 📸 **Vision & Window Inspection:** High-speed screenshots & window (`hwnd`) control.
- 🖱️ **Full Input Simulation:** Precise mouse clicks, scroll, and unicode typing.
- 💻 **OS Administration:** PowerShell/CMD, filesystem, process & registry management.
- ⚡ **Zero-Config Tunnels:** Auto-creates secure public HTTPS via Cloudflare/ngrok.

---

### ⚡ Quick Start

**1. Install & Run:**
```bash
pip install agent2win
agent2win
```
*(Console will print: `🌐 Tunnel: https://xxxx.trycloudflare.com`)*

**2. Connect Any Web AI:**
Paste this prompt into ChatGPT / Gemini / Grok / Claude:
```markdown
Read the official agent2win control protocol from this URL:
https://raw.githubusercontent.com/harikasinkaya/agent2win/refs/heads/main/AGENT_PROTOCOL.md

You are now an autonomous Windows controller agent.
My server URL is: <PASTE_TUNNEL_URL>
My API key is: <LEAVE_EMPTY_OR_PASTE_KEY>

Inspect system info, capture screen, and follow my commands.
```
